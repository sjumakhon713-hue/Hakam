Ҳакам — барномаи олимпиада (Windows)

Сохтани .exe тавассути GitHub:
1. Дар GitHub репозиторийи нав "Hakam" созед ва ҳамаи файлҳои ин папкаро бор кунед (папкаи app бо lib дохилаш).
2. Settings → Actions → General → Workflow permissions → Read and write permissions.
3. Actions → set up a workflow yourself → номи файл build-exe.yml → матни .github/workflows/build-exe.yml-ро гузоред → Commit.
4. Баъди 5-10 дақиқа дар Releases: Hakam-Setup.exe (насб) ва Hakam-portable.exe (бе насб).

Бе .exe ҳам кор мекунад: файли app/index.html-ро дар Chrome ё Edge кушоед
(барои PDF-скан беҳтар аст .exe ё скан бо формати JPG).
